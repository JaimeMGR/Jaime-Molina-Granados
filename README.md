## 📖 Sobre el proyecto

Portfolio personal desarrollado con **React, Vite y Tailwind CSS** para presentar mi perfil profesional, experiencia, formación y proyectos.

El portfolio está orientado a mis dos áreas principales:

- 💻 **Full Stack Development**
- 📊 **Data Engineering**

Incluye soporte multiidioma, diseño responsive, animaciones con Framer Motion, CV descargable, enlaces profesionales y Vercel Analytics.

🌐 **Portfolio:**  
https://jaime-molina-granados.vercel.app
